# Runner location artifacts and subscription configuration sync

## Purpose

Align CFIP with CFOpt's current runner-specific publishing convention and
subscription configuration assets.  Windows measurements represent Chengdu;
Linux measurements represent Beijing.

## Runner-specific artifacts

The workflow passes a runner location profile to the publisher:

| Runner OS | CSV artifact | Location token |
| --- | --- | --- |
| Windows | `CloudflareSpeedTest_CD.csv` | `CD` |
| Linux | `CloudflareSpeedTest_BJ.csv` | `BJ` |

The two CSV files are independent generated artifacts.  A Windows run stages
and updates only the CD CSV; a Linux run stages and updates only the BJ CSV.
This prevents a runner from replacing measurements made by the other location.
`proxyip-best.txt` remains a shared output and continues to be generated by
each successful run.

## CSV row identity and filtering

Published city values use CFOpt's current concise form:
`COUNTRY [LOCATION#NN S.SMB/s]`, such as `HK [CD#01 13.1MB/s]` or
`JP [BJ#02 10.0MB/s]`.  The country source is stored only as internal row
metadata while filtering and is not written to the ten-column CFOpt CSV.

The previously approved rules remain unchanged: valid measurements are
deduplicated by country/IP/port, ranked by download speed descending and
latency ascending, the first two valid rows per country are protected, and
subsequent rows must meet their country MB/s threshold.  Zero or one valid
row produces zero or one output row without failure.

## Subscription configuration assets

Copy the current CFOpt versions of the three Subconverter configurations into
CFIP:

- `CFOpt_Subconverter.ini`
- `CFOpt_Subconverter_lite.ini`
- `CFOpt_Subconverter_lite_cmliussss.ini`

Compare the `rules/` tree before copying.  It currently has the same file
inventory in both repositories; copy a rule only when its content differs.

## Validation

Tests must cover Windows/CD and Linux/BJ CLI profiles, including filenames,
city labels, and the invisible internal country field.  Existing filtering
tests must continue to prove country threshold and two-row protection.  A
fixture dry run verifies both profiles retain CFOpt's exact ten-column header.
